# 2026-09-11

## App icon concept exploration (Ardot canvas)

Designed four new app-icon directions for Monight, on a new Ardot canvas
(https://ardot.tencent.com/file/724649638917163). Exports written to
`design/app-icon-explore-2026/` as 1024×1024 PNGs.

- **A · 月出** — crescent rising behind a full-width page horizon. Light top / dark
  navy sky split at 56%. Fastest to read at 32 px. `A-moonrise.png`
- **B · 月缺** — page tilted −8°, crescent carved out of it with a single
  `fill-rule="evenodd"` path. `B-crescent-cut.png`
- **C · 半月** — circle split down the middle: cool paper white left, moonlight
  cream right, reading lines on the left. Most stable silhouette.
  `C-half-moon.png`
- **D · 开卷** — two page panels rotated ±9° into a V, crescent above the spine.
  `D-open-book.png`

Shared system: squircle `824 × 824` at offset `100`, radius `185` on a `1024`
canvas; navy `#0C182C` / `#2E5075`, moonlight `#FFF2CE` / `#FFD48C`, paper
`#FBFDFF` / `#C9DAEC`, body blue-gray `#8FAECF`.

### Existing brand, for continuity

Current shipping mark is 「一页月光」 in `design/app-icon-2026/`, built natively in
Icon Composer. Its background is `#0C182C` with a `#25415F → #0C182C` gradient;
UI accent is `#4A9EFF`. Any chosen direction should be re-layered into
Icon Composer's three material groups (Moonlight / Reading Page / Reading Session)
before replacing the shipping icon.

### Delivery notes

- Icons are hand-built vector SVG, not generated raster — app marks need crisp
  geometry and must scale, so ImageGen was deliberately not used.
- The small-size strip (128 / 32 px) is the real quality gate for an icon;
  re-inserting the same SVG at a smaller width/height scales it correctly.
- Regenerating platform assets afterwards: `npm run icons:generate`
  (reads `design/app-icon-2026/monite-native-default-1024.png`).

## Brand design kickoff (Miora canvas)

ssword asked for brand design for Monight. Scope was pinned by Q&A before any
generation:

- **范围**: 完整 VI 全案 (5+ assets, multi-batch) — not logo-only
- **图形锚点**: rebuild the mark from today's A–D explorations, primary = **B 月牙切**
- **语言**: 中英双语并列 (Monight + 墨页)
- **方向**: night-reading calm; navy base + single warm moonlight accent; motif =
  moonlight arc + page fold

Anchor chain: existing app icon PNG + `design/app-icon-explore-2026/B-crescent-cut.png`
are carried as reference images into every derivative. Never regenerate the mark
from text alone.

### Open brand problem worth fixing in the VI

The icon README claims the navy base "continues the product's dark UI and blue
accent", but the actual UI tokens in `src/styles/` are neutral gray
(`--bg-primary: #1e1e1e`, `--bg-secondary: #2d2d2d`) with accent `#4a9eff`.
**Icon and UI do not share a palette.** The VI should define navy as the brand
base and migrate the UI toward it, rather than bending the mark to the grays.

### Batch 2 — convergence (5 + 1 merge)

ssword picked **概念 5 + 概念 1** and asked for the Chinese lockup to be attempted
now rather than deferred. Four variations generated, all 1024×1024, same canvas.

Result, for the record:

| variant | verdict |
|---|---|
| A 内角落位 | usable — crescent now true circular arcs; moon reads slightly "cupped" |
| B 字腔落位 | strongest impact, but the cut breaks the M's outer contour; needs repair |
| C 笔画成页 | **failed** — the letter M disappeared entirely, became an open book with a floating crescent |
| D 双语垂直锁定 | lockup hierarchy works; crescent became solid cream (mono-reducible lost), M proportions drifed narrower |

### Hard finding — do not generate the Chinese wordmark

The Chinese lockup in variation D **reads** as 墨页 but the glyphs are not
orthographically correct. Verified by cropping and enlarging: 「页」 has an
unclosed inner 目 with a missing internal horizontal, and 「墨」's upper 黑 has its
two inner strokes rendered as detached solid blocks. Conclusion: generated
imagery cannot carry a wordmark-grade CJK lockup. A bilingual lockup must be set
in real type (system heiti), not rendered. Brand skill scope also excludes SVG, so
the vector Chinese lockup has to be produced outside this pipeline.

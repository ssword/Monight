## 2. 标志

### 2.1 锚点：笔触锁定

由三部分组成，垂直居中对齐。

**符号** —— 手绘笔触扫出的宽体大写 `M`。边缘毛、有纤维状笔痕、收笔带尖与拖尾；右腔内一牙暖米月牙，开口朝左上。身体由层叠碎笔构成：墨夜蓝与夜蓝为底，暗部沉睡莲紫与晨雾青，受光边（左上）走暖阳金。月牙用松动的暖米与暖金笔触画成。

**字标 `Monight`** —— 与符号同一套笔触做法，但**骨架优先**：七个字母必须一眼认出，读者不需要猜任何一个字母。做法是笔迹只做表面 —— 字腔开放、x 高度均匀、字距干净，笔触浮在骨架上做肌理与毛边。

**副标 `READ BY MOONLIGHT`** —— **严格字体**，全大写、宽字距、平涂墨夜蓝。它的职责是给画出来的名字一条安静的基线，**不要笔触化**。这组「画的名字 + 精确的副标」的对比是锁定成立的关键。

层级：符号最大 → 笔触字标 → 字体副标。

### 2.2 平面简化版（app 图标 / favicon / 工具栏小图标）

从笔触版骨架抽出的平涂形：保留它的比例与收笔斜切，压平全部肌理与颜色，只留墨夜蓝 `#0C182C` 与暖米月牙 `#FFD48C`。

⚠️ **已知妥协**：这一版的站姿回到近对称，与笔触版的倾斜不完全一致 —— 两者是亲属，不是同一个形。在极小尺寸下这个差别看不出来，但并排放在一起时会看出来。

32px 实测：`M` 剪影干净成立，月牙退化为一个暖色点 —— **小尺寸下的识别由 `M` 承担**，不要指望还认得出月亮。

### 2.3 暗底方案（三版分工，非三选一）

笔触标志是多色的，身体是墨蓝，所以旧的「整体转白」逻辑搬不过来。深色场合按用途分三种表现：

| 版本 | 做法 | 用在哪 |
| --- | --- | --- |
| **A 提亮笔触** | 笔触做法不变，身体改冷光：纸白洗蓝灰，暗部留紫青；月牙保持暖米与暖金，形成冷暖对撞 | **表达面**：海报、官网 hero、封面、发布图 |
| **C 夜色剪影** | 退成比底色略亮的夜蓝剪影，笔触压到几乎不可见；月牙是全场唯一亮点，背后一圈很散的暖晕 | **产品界面**：夜读需要静，发光的厚涂会吵 |
| **B 亮窗托底** | 标志原样不动，搁在浅色平板上，深色只是外场 | **文档与印刷**：标志必须完全准确的地方 |

规则：同一套笔触语言，三种场合三种表现。**不要混用** —— 在深色界面上用 A 会吵，在海报上用 C 会没有力量。

### 2.4 已退役

平面硬边几何标志（原主版 / 单色版 / 反白版三件）**已退役**，不再作为品牌标志使用；以它们为参考图派生的物料同样失效，保留的文件仅作历史对照。

### 2.5 用色规则

- **平涂场景**（简化版、字标以外的一切平面元素）：只用墨夜蓝 `#0C182C`、纸白 `#FBFDFF`、月光暖米 `#FFD48C`/`#FFF2CE`。
- **笔触内部**：氛围色**可以**进入标志 —— 睡莲紫与晨雾青做暗部、暖阳金做受光边。这是第二版相对第一版的改变（第一版要求氛围色完全不进标志）。
- 五个氛围色仍**不得**在标志上作大面积平涂。

### 2.6 单色：已妥协

ssword 决定单色还原不再作为硬门槛。保留的最低底线：**压印、盖章、传真级灰度下，`M` 的剪影与月牙的相对位置仍须可辨**。

### 2.7 待补

中文「墨页」的标准锁定尚未产出。**必须以真实黑体排版**（字号、字重、字距、与拉丁字标的对齐关系），**不得由图像生成产出** —— 生成结果会出现「页」缺横、内框不闭合、「墨」内部笔画分离等字形错误。

## 4. 层次与约束

第一版曾主张「风格只走色彩与氛围层，标志保持硬边几何」。**该主张已由 ssword 推翻** —— 风格现在直接落在标志上。现行分层：

| 层 | 内容 | 约束 |
| --- | --- | --- |
| 识别层 | 笔触标志、笔触字标 | 笔触化，但字标骨架必须清晰；副标保持严格字体 |
| 色板层 | 十一个色 | 平涂只用墨夜蓝／纸白／暖米；氛围色只进笔触与背景 |
| 氛围层 | 笔触肌理、水面光斑、雾、睡莲母题 | 用于启动页、官网 hero、空状态插画、发布图 |
| 产品层 | 内置滤镜预设「印象 / Impression」 | 把品牌坐进功能，呼应「一页月光」：同一种光，不同的时刻 |

**连作语法**：同一页纸、同一个标志，在不同光线主题下重复出现（夜 / 暮 / 晨）。社媒模板与启动页系列按此结构组织。

**色彩规则**：暗部不使用黑或中性灰，改用睡莲紫与晨雾青；高光偏暖。

## 5. 已知限制

1. **图上文字不可信。** 色值、字体样张、正文文案一旦交给图像生成就会出错（曾出现 `#06062E`、`#FBFTFF` 等错误色值、乱码伪拉丁、凭空多出的假标语）。需要画面里有"排满的字"时，让生成画**抽象色条**而不是真实文字，可完全避免乱码。权威文本一律以文字交付。
   - 2026-09-15 重锚时再次复现：VI 手册图上出现 `#0C1868`、`#FFFTFF`、`#6E67A6` 三个错值，色卡下方的品牌名被画成「Mombèa」，字体样张区混入一坨乱码字形。**现行做法：色卡下方不排色值，正文一律抽象色条，全图只保留 `Monight` 与 `READ BY MOONLIGHT` 两个真实字符串。** 按此重出后文字全部正确。
2. **中文不得生成。** 理由见 2.7。
3. **标志有两种形。** 笔触版与平面简化版站姿不完全一致，是已知妥协，见 2.2。
4. ~~现有 UI 尚未对齐。~~ **已对齐（2026-09-13）。** `src/styles/` 与 `settings.html` 已从「中性灰 + 电光蓝」收敛到本规范色板，映射见第 7 节。
5. **「印象」滤镜预设尚未实现。** 第 4 节把「印象 / Impression」写作内置预设，但产品现有预设为 `Default`／`Original`／`Redeye`／`Sepia`／`Custom`（见 `src/scripts/filters.ts` 的 `PRESETS`，按钮文案在 `index.html`），**没有「印象」**。第 6 节的滤镜界面示意因此分两版交付：印象概念提案 + 真实界面对照。**待定：改文档，还是排期实现。**

### 7.3 两条约束

- **暖米是唯一的强调色。** 强调色从电光蓝换成月光暖米后，所有「暖米底 + 白字」的组合都会失效，必须改用 `--text-on-accent`（墨夜蓝字）。已处理：启动页主按钮、激活的滤镜预设、弹窗主按钮、设置页按钮、开关选中态。
- **语义色例外。** 错误红 `#E2606E`、删除红 `#C9464F` **有意留在品牌色板之外** —— 状态色不能靠品牌色表达。
- **氛围色不进 UI。** 五个莫奈氛围色（睡莲紫／晨雾青／日出橙／玫瑰粉／暖阳金）已登记在色板，但**不进入产品界面**，只用于笔触与图像氛围。

| 组合 | 比值 |
| --- | --- |
| 纸白 / 墨夜蓝 | 17.4:1 |
| 纸白 / 夜蓝 | 10.3:1 |
| 月光暖米 / 墨夜蓝 | 12.7:1 |

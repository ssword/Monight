# Release-candidate fixture kit

Use this inventory with the [release-candidate test runbook](release-candidate-test-runbook.md).
Paths are relative to `src-tauri/tests/fixtures/`. Committed generated PDFs are reproducible; do
not replace them with documents containing private data.

| Fixture | Purpose | Provenance |
| --- | --- | --- |
| `tester-kit/valid-document-a.pdf` | Two-page valid Document with searchable text, outline, thumbnail-distinct pages, an internal link, and HTTP/HTTPS/mail/unsafe-scheme links | Generated by `node scripts/generate-tester-pdf-fixtures.mjs` |
| `tester-kit/valid-document-b.pdf` | Distinct valid landscape Document with deterministic content padding for ordered intake, restoration, aliases, and observable edits during a large Save | Generated by `node scripts/generate-tester-pdf-fixtures.mjs` |
| `tester-kit/invalid-document.pdf` | Existing path with invalid PDF bytes; use `tester-kit/missing-document.pdf` when a missing path is required | Hand-authored invalid input; `missing-document.pdf` is intentionally absent |
| `protected-documents/permission-restricted.pdf` | Allows reading and printing but forbids annotation editing | Generated by `scripts/generate-protected-pdf-fixtures.py` from the native original |
| `protected-documents/password-encrypted.pdf` | Exercises live password entry and password non-persistence; test-only password: `monight-test-password` | Generated by `scripts/generate-protected-pdf-fixtures.py` from the native original |
| `protected-documents/digitally-signed.pdf` | Exercises signed-Document read-only protection | Generated by `scripts/generate-protected-pdf-fixtures.py` with a generated self-signed fixture certificate |
| `native-annotations/original.pdf` | Monight-authored baseline without annotations | Exported by `node scripts/verify-embedpdf-offline.mjs --write-annotation-fixtures` |
| `native-annotations/annotated.pdf` | Monight-authored native highlight and note | Exported by `node scripts/verify-embedpdf-offline.mjs --write-annotation-fixtures` |
| `native-annotations/deleted.pdf` | The annotated fixture after Monight deletes both annotations | Exported by `node scripts/verify-embedpdf-offline.mjs --write-annotation-fixtures` |
| `external/preview-supported.pdf` | Placeholder: Preview-authored highlight and note for editable round trips | Added by the later external-fixture ticket; do not substitute a screenshot |
| `external/preview-unsupported.pdf` | Placeholder: the Preview supported fixture plus one unsupported native Annotation type | Added by the later external-fixture ticket |
| `external/acrobat-supported.pdf` | Placeholder: Acrobat-authored highlight and note for editable round trips | Added by the later external-fixture ticket; do not substitute a screenshot |
| `external/acrobat-unsupported.pdf` | Placeholder: the Acrobat supported fixture plus one unsupported native Annotation type | Added by the later external-fixture ticket |
| `tester-kit/fallback-font.pdf` | CJK (`你好`), Arabic (`لا`), and Hebrew (`שלום`) rendered as visible text without embedded fonts | Generated by `node scripts/generate-tester-pdf-fixtures.mjs`; Arabic uses its Unicode presentation form and Hebrew uses visual-order Unicode CIDs, with logical text retained in `ActualText`; consumed by the offline-assets contract and Chromium offline smoke |

Regenerate the general and fallback fixtures from the repository root:

```bash
node scripts/generate-tester-pdf-fixtures.mjs
git diff --exit-code -- src-tauri/tests/fixtures/tester-kit
```

The second command proves regeneration is deterministic. The local
`MonightMultiscriptFallback-Regular.ttf` asset is derived from the three pinned Noto Sans, Noto
Naskh Arabic, and Noto Sans Hebrew files under the SIL Open Font License. Regenerate it with
FontTools 4.65.0 and confirm that it is stable:

```bash
uv run --script scripts/generate-multiscript-fallback-font.py
git diff --exit-code -- public/embedpdf/fonts/MonightMultiscriptFallback-Regular.ttf
```

The protected generator requires the
versions recorded in `docs/issue-64-protected-document-verification.md`. The annotation fixture
export requires the pinned EmbedPDF runtime and installed Playwright Chromium.
